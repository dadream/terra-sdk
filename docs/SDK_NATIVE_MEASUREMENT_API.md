# 原生模型与测量生产接口

C ABI46把已有的CBDAM模型、整段投影和规范影像输入接到正式生产接口。Worker
协议为46，宿主区域仍为176字节v4；浏览器和Worker一起重新构建。
不提供旧ABI兼容。八根纹理模型、外部TMS/WMTS适配、1.25px目标和运行时容量
均未改变。

Worker46在每份占用回执中报告实际Wasm堆容量，包括影像进度、错误及取消；
客户端接收时更新，旧地形/网格结果不再回写容量。只有Worker实际终止后才
归零，缺失或倒退的同代占用报告会终止生产者。该统计不等于共享账本额度，
也不替代原有的分配前授权、数据借用或GPU提交回执。

Web、Worker与Direct准备器默认使用原生模型/测量生产器。JS仍负责渲染所需
模型摘要、视图变化提示和分区拟合；合成控制测试显式注入JS参考生产器，产品
不提供JS投影回退。默认切换本身不构成大倾角端到端时延改善的证明。

## 输入与任务身份

`terra_open_surface_model`只接受真实mesh资源。planId为0时借用驻留资源；
非0时借用该候选的冻结读取能力，遵循既有Float32采样，不物化整幅候选XYZ。
候选丢弃后，已打开的模型仍持有其冻结源。`reuse_model_id`仅借用兼容UV布局；
模型空间摘要和高程导数仍重新计算。布局本身不固定旧几何或高程。

SDK等待元数据额度时不冻结可选复用ID；打开模型时再读取句柄，闲置模型已被
回收就重新生产布局。候选计划转为驻留源时，尚未打开的任务读取epoch的最新
寻址，同一资源ID的内容保持不变。Direct的冻结epoch另外借用原生mesh，宿主
数组的loan不能替代C++源所有权；完成后的数值行不固定该源。混合地表在准备
时也取得测量数值loan，在提交或丢弃时转交或释放。

`terra_open_surface_measurement`复制投影矩阵、像素尺度及view/source revision，
绑定模型、资源、plan和影像会话。内部纹理锚点来自真实CBDAM资源，调用方不能
用外部TMS/WMTS节点替代它。调用方仍须把数据集、图源描述、视口/DPR和算法
版本纳入自身工作代次校验；本接口不会替运行时定义整套缓存或发布身份。

显式domain选择最多256项，每项为0..335中的模型来源码，须非重叠且真实存在。
空选择表示整幅模型；非空选择只测量指定域，**不代表完整mesh覆盖**。
`previous_measurement_id`支持完整快照的选择性细化：先分片检查旧规范区域，
保留精确投影行，仅测量标量域并写入同一个新规范所有者。全部行已精确时
直接共享旧所有者，不另申请投影工作区；空区域不视为完整性证明，执行完整
精测。旧结果必须与当前会话、真实资源、纹理锚点、投影矩阵、像素尺度及
source revision一致；部分domain结果不可用于完整快照合并。

准备器的source revision绑定同一投影生命周期。把全部松散测量移入待收紧
集合、使活动映射暂时为空，不改变这个身份；缓存重用也恢复对应投影身份。
实际矩阵、视口/DPR或图源投影身份改变时，才建立新一轮测量。

## 报价、推进与取消

元数据先用`terra_surface_model_work_bytes`或`terra_surface_measurement_work_bytes`
报价，再打开句柄。每次分配边界通过68字节`terra_surface_work_v1`返回需要的
字节和`quote_id`。授权须同时匹配任务句柄、当前quote和足够字节；差1字节、
其他阶段或已消费的quote均不能推进或分配。零授权必须同时传quote0。

模型阶段为waiting0、building1、ready2。测量阶段为inspecting_previous0、
work1、measuring2、input3、copying4、normalizing5、ready6，其后分别为
cancelled7、invalid_input8、allocation_failed9和internal_error10。仅ready允许读取规范结果。等待不是完成，
错误也不是不可见；适配器必须传播失败并关闭任务。

每次C step最多16384个工作单元，支持耗时窗口；Wasm适配器默认4096单元、2ms，
并接入既有4ms合作调度。256行/点是复制与归一化的检查点，不是总帧时延承诺。
分配、消息接收校验和发布重绑定的成本仍须在实际场景中核验。

`native_surface_measurement.js`在每次分配前申请对应阶段的精确字节。
Direct先获得现有input账户额度。Worker45用`ImageryInputBatch`合并同一次有界
host调用中的小额申请：报价包含精确下限与可选的64KiB偏好，只有账本现有空间
足够时才取得偏好额度；不能为偏好额度触发额外淘汰，也不能拒绝本可准入的下限。
额度只支付本次调用内实际经过的阶段，不预先生产未来视点的数据。

每笔原生分配仍校验任务、quote及精确字节；批次按报价累计消耗，释放不补回
授权余量。RPC结束前关闭已授权批次，实际回执确认后才结算账本；剩余额度不能
跨RPC使用。未授权的等待报价保留给下一次grant。取消和失败同样结束分配许可，
观察回调失败不能跳过许可释放，也不能提前退款。过期ID不能授权后继任务。
生产器与规划器使用独立的工作区通道，重建规划切面不会清掉等待授权的模型/
测量任务。空闲模型回收及Sender提交后的实际载荷变化回执继续保留。

一次准备操作可能跨越多轮RPC。暂停先标记整个逻辑操作，再取消当前RPC；
报价返回、旧授权回执或回收额度的等待期间，也不能发出下一轮授权。正在
执行的授权仍等真实回执后结算，兼容的测量状态保留给后续地形候选。

## 规范输入和实际持有者

`surface_measurement_work`依次完成有界计数、投影、压缩、最终输入准入、逐行
写入与归一化。确定行数后，向目标影像账户申请同一个最终规范所有者。
区域和凸包写完后，先释放原始区域、压缩暂存、模型和源loan，再归一化并公布
结果。历史或规划持有的规范输入不能因此留下整份生产工作区。

独立规范输入的封存不改变控制器当前切面。`terra_append_measured_imagery_surface`
把同会话的封存所有者加入当前输入事务，不复制区域数组。关闭测量句柄不退还
规划器仍持有的规范数据；最后一个真实loan关闭后，先释放存储再退款。

固定上下文槽位分别最多4096个模型和测量句柄；槽位表属于固定控制存储。
XYZ与共享UV按[实际分配所有者](SDK_NATIVE_MESH_PAYLOAD.md)计数，模型/数值
推进后的网格账户核验不再扫描全部弱注册表。
活跃记录、模型/UV/采样游标、原始行和压缩暂存均在分配前报价，计入既有input
载荷观察；规范输入继续计入其影像控制器。计量不等于Wasm容量、JS堆或进程RSS。
模型句柄和活跃测量共同借用真实源；封存后的测量只保留规范数值和身份。

会话关闭先退休它的全部测量句柄，再销毁控制器；模型可独立关闭。数据集替换
清空全部生产句柄，数字代次不重置，迟到授权不能命中新任务。适配器同步取消
迭代器及裸缓冲；ABI销毁同样关闭所有注册持有者。

## 规划和宿主镜像

`NativeMeasurementRows`是封存输入的显式引用，不暴露Wasm堆视图。规划适配器
直接追加该所有者，跳过JS逐行重打包；`MeasurementSender`按最多256行读取到
已获授权的独立mesh缓冲，接续Worker45真实转移及Direct镜像合同。

Sender当前缓存与活跃发布分别借用规范输入。结果初始loan释放后，发送缓存仍
可重发；取消、forget和clear退休相应借用。规范行不因此留住源模型。用于有界
读取的45060字节Wasm页按需报价一次，真实保留到ABI销毁，不能提前报告input0。

## 验证与后续

原生合同覆盖元数据/模型/投影/规范输入分配失败、少1字节、过量domain、重复/
错代授权、不同切片一致性、布局复用、跨会话拒绝、无区域复制交接、模型关闭
后封存结果可读、会话关闭和数据集替换。纯C合同固定68/176/64字节布局及字段
偏移。真实Wasm与JS准备器对照16组全球、斜视、贴地及DPR输入，其中8组可见
斜视、12组包含投影行；另检查选择域、候选丢弃、真实转移、Sender借用、远程
阶段回执和最终零句柄/零裸缓冲/零共享额度。源码和压缩模块执行同一合同。

完整构建、发布、本机18766部署与清理回执位于
`viewer_verify_output/native_measurement_api_20261020/`，保持数据盘挂载路径。
默认生产、选择性合并及实际资源生命周期的集成证据保存在
`viewer_verify_output/native_measurement_merge_20261020/`。历史、准备器、响应和
待发队列独立借用规范数字；模型绑定实际网格，空闲模型可按共享额度压力回收，
不影响独立数值快照。数据集替换后重建生产器。

Worker45批次合同增加精确下限回退、同一调用多阶段复用、交叉等待任务、过期
授权、取消前后回执，以及原生调用和观察回调同时失败时的许可释放。真实Wasm
比较完整规范行字节；实际Worker在每轮结果检查没有可跨RPC复用的许可。固定
视点三轮串行对照的切面及全部质量字段相同，Node规划中位数2540ms降到1389ms，
RPC8247降到1495，资源峰值相同。这是桥接授权的局部收益，浏览器大倾角仍需
8.3–14.4秒停稳。19项完整基线、实际分发包与348项浏览器门控通过；详见
`viewer_verify_output/native_credit_batch_20261020/`。

受限容量联合发布的完整产品验收、20秒停顿、真实帧/输入时延、步行坡面和
设备/API验收仍待完成。整体P0–P4继续；49服务器只作为数据上游，不部署更新。
