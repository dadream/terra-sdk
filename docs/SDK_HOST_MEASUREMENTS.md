# 紧凑宿主测量镜像

Web/Direct-Wasm的测量结果现在以独立计费的紧凑镜像进入渲染器。宿主不再将
每行区域解码为投影数组、三角形数组和JS行对象。当前C ABI46，Worker协议45；
浏览器和Worker一起构建，不保留旧的整包区域协议。

默认测量生产现已切换到[原生生产器](SDK_NATIVE_MEASUREMENT_API.md)。准备器、
数值历史、响应、待发队列和Sender分别持有规范输入；借用只保留数值，不固定
地形模型。队列在释放响应前取得借用，Sender提交导致的载荷下降另发实际回执。
本变更保持原有误差和预算，端到端时延仍须由实际轨迹测量。

## 分配、传输与发布

`measurement_delivery_host`串行发布测量快照，RPC、地形和控制队列继续独立
推进。每次发布首先报价`workId`、序列、实际新增数值字节和复用引用。宿主在
收到报价时先借用引用，再观察Native账户、申请共享ResourceLedger额度。
报价本身不创建数值缓冲。

宿主通过同workId的grant授权准确字节数。发送端每轮最多写256行，每个mesh
拥有独立的完整ArrayBuffer。行使用176字节v4混合布局，包含显式存在标记和
来源域码；不量化误差、不删掉局部投影证据。一小块旧显示不会因此持有另一个
高密度mesh的大缓冲。

真实postMessage转移缓冲后，发送端才提交引用历史。每次发布带完整数据或
零载荷取消回执。接收端先核对完整后备缓冲、授权字节和序列，再把原授权拆分
为每mesh的宿主所有者，不重新分配区域数组。缓存里不存在的旧引用要求发送端
重新发布同一个不可变结果；不重跑地形或测量。缓存淘汰和新报价交叉到达的
情况也使用此流程。

Direct-Wasm使用相同Sender、Receiver、紧凑区域类型和共享预算；授权与交接
在本地执行，256行之间通过现有CooperativeTurn给宿主执行机会。

## 借用与退役

`MeasurementRows`只暴露数值读取、区域相交和受控复制，后备缓冲保存在私有
所有者中。结果、接收缓存、当前计划、显示过渡和held candidate显式持有loan。
渲染器查询局部密度和覆盖时直接访问该类型。

- RPC最终结果带临时结果loan；内部调用方在采用或丢弃后执行
  `releaseMeasurements`。流式回调返回后，由客户端关闭临时结果loan。
- MeshFrames只借用候选交接阶段的测量。Runtime交给渲染器后关闭结果loan，
  同时移除帧上的交接元数据，避免几何的较长生命周期固定旧相机投影。
- 渲染器为实际仍在使用的当前、显示和过渡快照独立借用。取消Worker、清空
  接收缓存不退还这些显示仍持有的数值。
- 仅缓存持有的镜像可以回收；回收同时通知发送端忘记该版本。最后一个loan
  关闭时先清除实际数据引用，再退还额度。残留的行元数据不能继续保有后备缓冲。

谱密度/裁剪使用一个按需分配的576字节工作区，分配前纳入同一ResourceLedger，
关闭渲染器时先清空数组再退款。既有256项局部密度memo仍只缓存数值结果。

## 取消和退出回执

发出取消意图并不退款。授权可能仍由发送端的部分缓冲、在途转移或宿主事件
队列持有；只有完整数据交接或发送端确认已经清空的零字节回执能结束该授权。

正常销毁时若存在已发出的正字节授权，客户端先请求`measurement-stop`。
发送端关闭后续镜像发布、清空待发送缓冲，再沿相同FIFO通道发出停止回执。
此前已转移的事件因此先被接收/丢弃，之后才终止Worker。受控fatal通知也在
关闭镜像队列后携带这一镜像停止屏障；Native内存仍另外等待平台终止回执。

单纯Worker终止不能证明已转移到宿主、尚未被观察的事件缓冲为空。异常崩溃、
停止超时或不完整数据回执保留未确认的在途额度并报告错误，不能为了得到零
账户而强行退款。尚无完整屏障证明的异常路径仍是P1生命周期限制。

## 验证和后续边界

新增检查包括冻结/边界区域的22410次局部误差精确对照、渲染器层级/局部区域
查询、真实MessageChannel转移、逐mesh回收、旧显示借用、引用失效重发、容量
拒绝、256行分片、取消回执及停止屏障缺失。真实Wasm/Worker和Direct候选测试
显式关闭临时结果，现有源码及压缩包门禁使用相同合同。

接收端数值校验和元数据重绑定目前仍是一次同步遍历；256行界限约束发送端
复制，不是完整宿主接收时延保证。JS生产阶段及其原始对象、完整数据源/工作/
视点身份、原生生产授权/退出回执和Web生产切换继续按
[同侧测量方案](SDK_FUSED_MEASUREMENT_PLAN.md)推进。受限容量联合发布、实际
帧/输入延迟、步行坡面及其余P0–P4和设备验收仍未完成。

`viewer_verify_output/packed_mirror_20261020/`。该路径保持数据盘绑定挂载，49服务器
只作为既有数据上游，不部署应用或服务。

大倾角停稳仍约10.3–14.0秒，原生生产与完整工业级时延验收继续开放。
