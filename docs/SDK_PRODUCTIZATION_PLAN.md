1. 固定验收：现有泰安33点/10倾角点参考继续保留；新增连续缩放往返与北京
   76.3°转向固定路径。采集与判定分离，超时、未执行运动、精度/覆盖不满足、
   缺失测试输入和退出资源未归零均不能通过。固定1.25px与每端点30秒上限；
   该上限表示功能收敛，不等同30FPS或工业级流畅。新用例先冻结基线再改运行码。
   泰安570.521491m端点沿用静态参考的明确源级别限制：最高物理级17时误差
   1.3961891432px；仅该端点允许在完整、空闲、不可再细化且不劣于参考时
   标记source-limited，不能标记target-met。其它端点必须满足1.25px。

## 当前实现与后续边界

CBDAM是唯一地形模型；全球影像使用固定4×2八根内部四叉树，外部TMS/WMTS
由适配器转换。地形锚点、纹理拓扑和误差约束保持一致。模型选择、测量、
资源生产和显示交接分开推进，不能用缓存数量代替最终需求集合。

本轮已交付的机制包括：持久地形粗化/细化、共享Native测量、Direct/Worker
共同候选事务、完整分组准入、编码图片提前下载、稀疏粗覆盖、已就绪细图跳过
可选中间层、驻留覆盖复用及GPU回执后释放。默认影像额度256MiB、共享768MiB
来自完整交接工作集测量；显式小预算仍作为压力测试，512KiB仅为包体积参考。

以下项目仍是后续产品目标，不因本轮功能验收而宣布完成：

| 方向 | 待完成保证 | 验收依据 |
| --- | --- | --- |
| 大倾角与长距离飞行 | 更短的尾部等待、移动中更一致的纹理精度 | 固定输入和路径，多轮同集合对比；真实图源单独记录 |
| 运动视觉质量 | 减少粗细拼块、闪烁和层级色差 | 连续画面与像素检查，不能只看SDK状态计数 |
| 徒步与近地导航 | 高程等待、遮挡、相机地面约束的完整应用体验 | 起伏地形路径和独立高程参考 |
| 移动端 | 设备适配、低容量策略及真实帧率 | DevTools、Android、iOS设备验收 |
| API与维护性 | 稳定公开接口、减少大型协调器的职责交叉 | 安装包消费者、模块边界和独立所有权合同 |

推进顺序是先复现并证明具体问题，再做有边界的修复，最后集中验收和交付。
不为删除代码而删除所有权检查、粗覆盖、失败样本或小预算反例；不把扩容、
增加并发、改误差或延长期限当作调度问题的通用解法。

## main集成review（2026-10-27）

以`e361b81`为main基线，审查`18d5f68`的完整最终差异。原342个开发提交保留
在`feature/miniprogram-sdk`及本机备份分支
`backup/miniprogram-sdk-before-review-20261027`，集成使用一个新的提交。
本节记录代码与文档整理，之前的Web验收仅是输入基线，不替代集成后验收。

已复现并修正：

- 请求启动时尚未登记活动槽位，重入回调可以突破并发上限，启动中的暂停
  也会漏掉取消。现在先登记槽位再调用生产者，串行推进队列并补发取消。
  新反例在原代码失败，覆盖并发、启动中暂停和同步异常后的队列恢复。
- 全平台重新打包未清除已移除模块，只对小程序或旧入口名做特例清理。
  现在按当前依赖图清理两个生成模块目录，保留独立Wasm、许可证等资产。
  新反例在原代码失败；现有平台切换、独立消费者及隔离合同继续保留。
- 移除无用导入及重复纹理父节点算法；保留唯一父节点计算，不改变目标集合。
- Web门禁外层默认45秒已落后于完整套件（本轮370项用时约227秒），会让
  直接执行及CI提前超时。默认改为本轮实际验证的600秒；各导航场景的
  收敛期限不变。此次仅对齐默认配置，复用相同有效配置的已通过结果。
- 移除156个二进制测试数据文件的执行权限；测试数据内容不变。
- 当前架构、发布说明和产品计划改为描述最终状态，移除重复迭代流水、旧ABI
  和过时容量/包体积约束。原文随备份分支保留，原测试输出继续留在数据盘。

集成工程门禁、导航回归和最终提交/推送/本机部署状态记录于
`viewer_verify_output/main_review_20261027/`。只有这些检查完成后才声明集成交付。
不执行preflight，不更新49服务器，不将移动端未验收内容声明为已支持。
