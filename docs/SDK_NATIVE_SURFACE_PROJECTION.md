# CBDAM精确面的原生生产边界

2026-10-19：`Terra::frame`增加`surface_source`、`triangle_projection`和
`surface_projection_work`。它们将已选精确面的真实CBDAM读取、计数、逐行生成
和区域压缩放在同一侧完成，是[同侧测量方案](SDK_FUSED_MEASUREMENT_PLAN.md)
的生产核心。当前尚未替换Web测量路径，不能将专项正确性解释为交互提速。
CBDAM、八根纹理树、外部TMS/WMTS适配和像素误差目标不变。

## 同一个不可变几何输入

`surface_source`只读取CBDAM片段。已有XYZ数组和独立UV数组保持实际共享借用，
不会复制一幅网格来测量；未生成的XYZ保留候选冻结的`height_storage::block`，
调用与网格生产相同的Float32采样函数。打开时确定读取方式，后续生成数组或
后台高程细化不会让同一任务改读其他输入。UV未生成时使用相同的锚定采样。

每次读取最多64个顶点。测量工作在已授权的状态区内放置三页、每页32顶点的
缓存，避免按每面重复计算相邻顶点，也不物化完整候选XYZ/UV。几何、高程和
已选面布局由原持有者计费，借用不重复收费；缓存有独立工作报价。

`sdk/src/c_api/mesh_source.hpp`是私有上下文桥接。plan0只打开驻留资源，非零
plan只打开当前候选及其冻结高程；过期plan不能重新打开。它没有新增公共C
导出。隔离Wasm合同直接使用这个真实桥接，未用另一套采样器模拟候选。

源快照可在原上下文退休后继续被已存在的借用者读取，这证明实际所有权，**不
授权将旧结果作为新视点发布**。上层测量管理仍须校验数据集、plan、mesh/UV、
投影、视口/DPR及work/grant代次，并在失效时取消。相关C ABI/Worker接入尚未完成。

## 生产、压缩和额度

```text
waiting_for_workspace → counting → waiting_for_regions
         授权状态/缓存          授权原始区域 + 压缩工作区
                                      ↓
                                 generating
                                      ↓ 不可变语义行视图
                                  compacting → complete
```

首先只申请固定状态和缓存的实际字节数。计数对调用方已选的精确面执行同一套
投影、反面判断、齐次裁剪、密度和扇形计数，不创建原始区域数组。它统计实际
输出数量，不按每面最坏14行申请全幅容量。

计数结束后，原始区域与压缩工作区一起预留。`payload_budget::split_work`
只在同一预算的工作额度间拆分，要求目标未附着，拒绝时不改变双方；拆分不
经过退款再申请，也不改变预算总量或峰值。原始区域才开始分配、逐行构造。
压缩额度提前持有，待原始区域全部完成后交给压缩器，不双重申请。

`region_compaction_work`现在接收`measurement_region_view`，替换了原先的
vector专用输入。它直接读取已构造的语义行，避免一次性初始化完整vector或
通过C/C++结构布局做别名转换。视图可以保留共享所有者；无共享所有者时调用方
必须保证存储活到压缩任务结束。本工作将压缩器嵌在状态区，确保先结束压缩、
再释放原始行。开发期直接更新所有调用者，不保留旧输入接口。

工作区合计只有三次定价分配：状态/缓存、原始区域、压缩暂存。计数后才知道
后两项的实际报价；全不可见输入只需要第一项。`authorized_bytes()`还包含尚未
分配的压缩额度，`allocated_bytes()`只记录实际指定载荷，不能混作进程RSS。
外层对象、调用方的源/面布局和分配器开销另有持有者，不声称完整P1预算闭环。

## 推进、输出与取消

`step`同时接收操作数和时间窗口。计数按面推进，生成按投影或一行输出推进；
压缩将剩余操作数和时间窗口交给已有持久任务，不每个压缩动作重复返回跨边界
结果。内部每64动作检查时间窗口，页读取和单三角形裁剪有固定上限。这是协作
让出，不能等同分配、释放或主机调度的硬截止时间。

输入非法、读取/数值不能完成、分配失败、容量上限和内部错误为显式终态，保留
已有结果的调用方不得将它们当成精度收敛或I/O等待。等待额度的step不自动轮询
准入；调用方在容量变化后显式继续。读取结果最多256行，未完成和取消不输出。

取消先销毁压缩工作及其存储，释放原始行，再归还对应额度；最后释放缓存和
状态、归还状态额度，结束源/布局借用。错误和完成均须由调用方取消或销毁，
才能结束这些所有权。一个任务取消不能退还同预算里其他任务的工作。

## 验证范围和下一阶段

冻结参考`surface_projection_v1.bin`包含65例，覆盖裁剪六面、透视近裁面、
反面、零/极小深度、UV退化、正负零、坐标平移和固定随机输入。Native逐字段
比对该JS参考，并对平面/球面真实CBDAM生产结果做冻结与驻留读取的字节对照。
八档组合、两次准入各少一字节、联合额度、实际分配观察、释放前计费、双任务
竞争、部分取消和实际分配失败纳入同一合同。

独立Wasm运行同样65例；再用现有非平坦CBDAM记录执行候选、混合生产、驻留、
后台高程变化、内存增长及源退休的整段对照，输出与独立JS投影和冻结旧压缩器
比对。测试导出仅存在于`tests/wasm/surface_projection/`的构建，不进入产品。
专项、ASan/UBSan、完整基线、发布和本机部署分别留证于
`viewer_verify_output/native_surface_work_20261019/`。

上述是**已选精确面**的工作单元。后续已补齐[原生块模型与整段测量](SDK_NATIVE_SURFACE_MODEL.md)，
包括浅视保守上界、两级域选择和按需收紧，不能让全视图无条件逐面扫描。
下一阶段还需规范原生影像
输入、受预算约束的宿主镜像、完整身份与跨线程回执，最后移除JS对象重建和二次
打包。当前C ABI43/Worker41及Web行为保持原合同；没有增加逐面Wasm接口。
受限容量联合发布、20秒停顿根因、真实帧时延、步行/坡面、外部设备/API验收和
其余P0–P4仍按原范围继续，不能用上述合同代替工业级场景验收。
