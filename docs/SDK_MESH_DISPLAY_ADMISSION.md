# 地形替换的显示后继准入

本轮补齐网格生产与派生显示准备之间的一段所有权边界，保持CBDAM、八根影像树、
误差和默认预算不变。它是P1的增量，不是最低联合容量或完整产品验收。

## 驻留索引的联合所有权（2026-10-21）

GPU索引已独立准入，但此前主线程索引和Worker保留的JS索引没有租约，Direct首次
交接还会复制一次相同strip。现在`MeshCopyPlan`按完整draw索引范围，在物化前计入
缺失的主线程strip；Worker另报生产端的新增索引，使用同一事务的预付额度。
Direct将已付费的同一个数组交给私有表面和主线程，不创建额外接收副本。

索引自身、帧、网格模型和GPU索引各有明确持有关系。清空帧或取消候选只退役其
生产者，不能退款任务或提交中的GPU命令仍借用的数组。Worker47的每个所有权
封包报告实际索引占用；取消、失败及空闲回执均参与更新，线程终止意图不等于
终止回执。C ABI46保持；旧Worker/host配对直接拒绝，不保留兼容路径。
空候选不读取或缓存未来完整strip，后续首次有网格时仍须重新准入。
空候选没有GPU索引需求，即使其零字节生产者已退出，显示也不能创建索引上传
待办。非空来源借用失败则归还尚未使用的GPU额度，不能留下阻塞后续上传的游标。
首次非空私有候选的UV报价可借用候选自身已付费的strip，不依赖空的已发布帧。
报价批次持有该索引直到最后一行、取消或失败；尚未开始的取消同样归还借用。

真实非平坦CBDAM的Direct/Worker诊断使用同一捕获地形、168MiB总额与1.25px目标。
两条路径的主线程strip均为8826字节；Worker再持有独立的8826字节。生产获准后
竞争者只留下8192字节，已预付的单个完整边界组均取得实际显示回执，之后恢复
精度并销毁归零。该GL合同诊断不证明实际GPU时延或最低联合容量。
证据在`viewer_verify_output/resident_indices_20261021/`。

本增量纳管的是JS驻留索引。C++固定索引容器、`copyVector`的原生临时输出、
派生表面摘要、共享三角拓扑及其他临时元数据尚未全部进入联合报价；账本不是
进程RSS或Wasm堆上限。不能据此宣布完整元数据、最低联合容量或P0–P4已完成。
旧源码在同一所有权合同中因首个strip未计入生产报价而失败；专项同时检查一个
字节不足、Direct复用、任务/GPU借用、空切面及Worker实际终止回执。

## 生产与显示交接

Direct私有候选的原生借用与宿主副本现在共享同一不可变源的派生模型。
绑定发生在副本与成员校验之后、原生提交释放借用之前；所有几何持有者都退出
才关闭模型，失败发布则通过副本退役解除绑定。活动测量仍受保护，压力回收会
移除全部绑定，不能保留悬空句柄。数据集重置已关闭的缓存不参与纯几何发布。
这避免交接丢失缓存，不保留退役几何，也不把逻辑发布当成GPU完成回执。
真实执行器对照、拒绝/取消/回收合同及实际GPU验收见
[模型交接修复](SDK_MEASUREMENT_PIPELINE.md#direct模型发布交接修复2026-10-22)。

此前`MeshOutputPlan`预留原生/host/GPU几何和CPU/GPU UV，但`WorldDisplayPlan`
在接收新地形后另行申请数值切面工作空间。几何已付费不保证显示后继能生成；旧
表示又必须保留到真实显示回执，紧额度下可能停在两者之间。

现在真实帧的替换事务在物化前完成必要的数值显示切面。它与普通世界更新共同调用
`WorldDisplayPlan.buildCuts`，不新增选级器。临时工作与边界证明、UV报价和生产
工作区共享顺序阶段的峰值；生成的数值切面取得独立resident租约，继续留在同一
账本。无法支付时，私有切面退役，原显示不变，不开始未付费的后续物化。

接收不可变地形后，资源时钟核对完整来源身份和图源代次，再接管已付费结果；
不再为同一交接重复申请全量世界准备。真实图像和UV仍由`PartitionPublication`
检查，命令提交和GPU回执不跳过。交接完成前保留已持有的细纹理端点，避免将
较早相机的粗化判断用于新视点；交接后普通影像任务按当前误差独立粗化/细化。

这个切面只证明已付费空间覆盖，`demandStamp`不标记当前精度已规划。真实显示
回执之后，普通世界准备与精度任务继续。未变化的数值行可以借用原始payload，
新发布仍支付自己的列表/分组成本；借用直达payload，不累积发布版本链。

取消、暂停、换源、失败或候选废弃会释放未接管结果；已接管切面由世界管理器
持有，原生产者退出不退款仍在显示的payload。外部矩阵偏移先按同一个来源模型
归一化，覆盖凭据使用实际已报价的足迹。

## 专项证据和边界

`tests/wasm/terrain_world_admission_contract.js`运行真实CBDAM Wasm、Direct及
真实Worker、实际运行时、渲染器和UV生产；GL命令与64像素合成图片由合同对象
承接。实例从构造到销毁保持3MiB，1.25px目标不变，上传窗口选择完整原生边界组。
在生产已经获得额度后，其他任务占用剩余空间，只留下8192字节命令额度；已付费
局部后继仍实际绘制并确认。退款后达到四网格目标，再粗化/细化往返，销毁归零。
这不是实际GPU像素或全球最低容量证明。其他小额度合同明确只验证buffer分配，
不以它们的旧字节数宣称包含整个显示链。

冻结前专项中局部切面resident34560字节，工作包络峰值57828字节。Direct/Worker
局部回执约188/137ms，退款后精度恢复约203/218ms；这些是一次本机合同观测，
不作固定工作量性能提升结论。精确`2cb2675`的Direct在原30秒内不能确认局部
后继；其Worker执行未满足显示后继已计费断言，不能宣称两种模式都证明同一停滞。

独立恒定2MiB探针能交接四网格并维持约1.17px的实际覆盖，但原生影像输入续作
仍等待，30秒未达到完整ready。探针失败保留，不把仅targetMet当作收敛，也不
通过扩大SDK默认预算解决它。完整原生精度续作、全部元数据计量、最低联合容量、
大倾角时延与真实图源/设备长测继续沿P0–P4推进。

## 竞争回收暴露的传输引用缺口

首轮完整baseline通过，但随后发布的Worker竞争占用合同失败：已有付费数值
切面，分区生产却因`Unclaimed measurement transport regions`停止。失败源码、
基线和发布日志保留在`before-retained-reference-fix/`，未提交或部署该版本。

确定性传输合同复现了跨方向消息顺序：发送方在`keep`中声明保留历史测量B，
本次`entries`只含A；旧`references`仅保护A。主机取得grant之后回收B，forget
消息尚未到发送端，较早的数据包就携带仍含B的keep抵达，接收方完整性检查失败。
现在references来自整个下一状态的旧版本，覆盖不在当前entries里的保留项。
主机在发出grant前保护这些引用，到传输回执后释放；已缺失的项继续走既有resend。
不取消完整性校验，也不把错误降级为成功。相同反例先失败后通过，真实Worker
整链和恒定3MiB合同通过；消息格式、C ABI46/Worker46保持。

随后硬件Web验收在初始全球视图停止：规划1.2376px且全部目标图片驻留，实际
仍2.6462px、31处回退，队列已空闲。确定性合同确认了共享payload的边界：旧
发布尚未完成时，其行保留未ready的状态；复制这个引用到新发布后，旧状态机
已退出，新发布自己的就绪状态却不能被那些行读取。现只共享已就绪的不可变
数值行，待发布行必须取得新发布自己的状态，旧借用者不被修改。反例先失败
后通过，并验证已就绪行仍共享同一payload、退出归零。失败浏览器与源码保留
在`before-payload-readiness-fix/`，不以已规划或已驻留替代真实呈现精度。

之后的硬件检查通过初始全球视图和24份严格内存回放，但斜视运动1802ms内
只有2次更新/发布、0次网格变化。固定候选49的数值准备从约796ms延续至
运动结束，工作包络由212508增至471130字节。旧account对每条记录重新扫描
完整几何/UV报价，已持有的工作区仍被反复检查。现直接使用已付费空间，
仅不足时重算完整价格；可用余额允许时批量持有最多64KiB续作空间，不为额外
批次驱逐资源，结束后退回多余额度。实际最小工作量继续单独记录。固定覆盖
合同确认旧实现重复报价，新实现不重复，真实Direct/Worker恒定预算仍通过。
失败场景与源码保留在`before-world-workspace-amortization/`。这不等同于消除
全视图准备、所有不可中断步骤或最低容量要求。

完整工程门控及发布记录保存在
`viewer_verify_output/joint_world_successor_20261020/`。最终671份SDK/测试/安装契约
冻结输入通过19项baseline，编译警告0；硬件Web366项、12条可见轨迹通过。

1次预热、2次测量、每圈8视点及第二测量圈零增长门槛，不作历史增长已全部归因
或长期无增长的证明。

四条斜视轨迹停稳14.1–21.1秒、最终误差1.2439–1.2483px。1.25px目标、
