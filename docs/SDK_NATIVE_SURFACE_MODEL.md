# 原生CBDAM模型与整段视点测量

`Terra::frame`在既有[精确面生产](SDK_NATIVE_SURFACE_PROJECTION.md)上补齐完整
UV布局、几何块摘要和视点选择。整段测量复用同一个计数、生成及压缩任务，
不是分块压缩后再拼接。CBDAM、八根纹理模型、外部TMS/WMTS适配和像素误差不变。
这是[同侧生产方案](SDK_FUSED_MEASUREMENT_PLAN.md)的核心实现；现已接通
[规范影像输入](SDK_CANONICAL_IMAGERY_INPUT.md)的直接生产接口。Web、Worker和
Direct现已默认接入[原生生产器及紧凑宿主镜像](SDK_NATIVE_MEASUREMENT_API.md)。
完整场景时延、受限容量和平台验收仍按P0–P4推进。

## 模型和所有权

`surface_model_work`读取冻结的`surface_source`，最多每次采样32个顶点；没有
完整XYZ/UV副本。模型分为两个不可变所有者：

| 所有者 | 内容 | 复用与退休 |
| --- | --- | --- |
| `surface_layout` | CBDAM面拓扑、UV范围/凸包、4×4分组及稳定面序 | 精确UV身份相容时复用；最后一个布局借用者释放 |
| `surface_model` | 真实源借用、每块XYZ范围、导数区间及残差 | 属于本次几何输入；最后一个模型借用者释放 |

面序由CBDAM三角网格行结构直接产生，与实际strip去退化后的绕序一致。
UV退化面保留在拓扑中，但不加入测量分组。凸包只访问三条边的3×D个边界顶点，
D为网格维度；排序、去重和凸包均有持久游标。

布局只记录UV数组的弱所有权身份，不能通过缓存旧模型继续占用旧高程或XYZ。
驻留数组要求同一个真实UV所有者；采样输入按精确CBDAM配方比较，规则化全球
UV可按维度和八种方向复用。高程、导数及可见性不能随UV布局复用。
这些引用计数和工作属于单一执行器，不提供跨线程并发修改能力。

构建前一次报价同时覆盖状态/采样/排序暂存、模型arena及需要新建的布局arena。
全部实际分配成功才接收调用方额度，拒绝保留原额度。完成后将两个arena的额度
转为驻留；`take_model()`释放暂存并转出真实模型借用。部分构建不能发布布局。
复用布局不复制或重复收费，其原持有者的预算继续有效。取消和最后一次释放均
先销毁存储、再归还对应额度，不退还同预算里其他模型或任务的空间。

## 浅视、困难区域和精确路径

`surface_projection_work(surface_model, ...)`执行完整选择：

1. 对根块执行导数区间面向判断及包围盒可见性判断。盒与视锥相交时同时裁剪
   两者的边；保留现有Float32逆矩阵语义，避免漏掉视锥在盒内部的情形。
2. 完整可见且最大深度不超过最小深度1.2倍的浅块，使用现有导数区间上界。
   投影后残差取两个保守上界的较小者，不逐面求解整幅浅视图。
3. 非浅块在深度小于2且面数大于64时，按UV质心分为2×2组；只对实际困难
   域细分。第一次需要细分时才报价并分配稳定面序、暂存面序及最多320个子域。
4. 深块精确裁剪可见三角形，保留局部投影证据；浅块收紧时扫描实际面密度，
   最后仍输出该块保守UV包络的一条标量区域，避免折叠地形膨胀成逐面输出。
5. 一次计数统计实际标量及投影区域数量。确定数量后联合申请原始区域和压缩
   空间；生成时复用已经完成的叶选择和细分顺序，再统一压缩。

纯标量输入不申请压缩暂存。完整模型状态/缓存是一份定价分配；困难域额外一份，
有输出时原始行一份，有投影行时压缩一份。指定载荷按实际所有权核对，不将
预算数值当作JS堆、Wasm容量或进程RSS。源/布局借用仍由各自所有者计费。

```text
waiting_for_workspace → counting ───→ waiting_for_regions
                           ↕                  ↓
                waiting_for_subdivision   generating
                                              ↓
                                         compacting → complete
```

等待阶段只接受显式同预算工作额度；未授权的`step`不推进。每64个内部动作
检查时间窗口，单次页读取、盒裁剪及三角形核有固定上限。这是协作式推进，
不等于分配器、最终释放或宿主调度的硬实时保证。输出最多256行一页。

当前精确叶按与原实现相同的右子树优先顺序访问64面小段，未复制JS的逐段空间
BVH缓存。根块和两级子域仍执行空间剔除，段内靠精确裁剪拒绝不可见面。
因此结果合同保持，部分相交叶可能多访问一些面；尚不能据此声称所有设备上
优于JS路径，端到端接入前须计入这部分计算及模型/镜像成本。

## 按域收紧与身份

标量区域携带当前模型内的来源码。测量根块编号r使用`r*21`，第c个非空子域使用
`r*21+1+c*5`，其第g个非空孙域使用`r*21+2+c*5+g`。编号按非空分组的稳定
顺序，每个网格最多16个测量根块、两级细分；SDK内部纹理树仍为八根结构。
调用方提供已持有的不可变码视图，不复制代码数组。

收紧只重建请求路径；重复、祖先/后代重叠、越界和实际不存在的子域显式拒绝。
一个范围合法但没有对应子域的码不能被解释为不可见或已收敛。有效域被背面/
视锥剔除则可以正常返回空结果。来源码不保持旧模型/源的强引用。

来源码不是全局资源ID，也不授权旧结果发布。完整数据集、mesh/UV、plan/驻留
代次、投影、视口/DPR和work/grant身份仍由后续管理层校验；保留冻结源只证明
读取所有权，不能代替最新视点的采纳检查。

## 验证与接续

Native合同检查D1/2/3/4/16/64/256的真实CBDAM索引、分组、包围范围、弱UV
身份、不留住旧高程、复用后的新导数、精确分配、少一字节、失败、取消和双任务
隔离。浅块操作数检查防止全量面扫描；两种分片尺度必须得到相同结果。

隔离Wasm直接读取真实候选/驻留源，以现有JS完整准备、选择和冻结旧压缩器作
独立对照。33组包含实际命中地形的近地大倾角、浅视域收紧、混合生产、背景
高程变化、内存增长及源退休；比较模型、原始数量、压缩顺序/字段和域来源。
另保留65例冻结投影与12组真实精确面合同。测试符号不进入产品分发。
专项及完整门控证据保存于`viewer_verify_output/native_surface_model_20261019/`。

本机Sanitizer使用`-fsanitize=address,undefined -fno-pie -no-pie`、默认信号处理、
泄漏检查和30秒执行上限。不含SDK的最小程序在5次PIE运行中有2次重复信号，
5次非PIE均通过；最终SDK合同在非PIE下通过。详细环境根因尚未确定，不能将
该工具启动问题当作SDK故障或修复收益。原始失败日志经逐字节校验后无损压缩，
对照及最终结果分别见`sanitizer-environment.json`和`sanitizer-verified.log`。

2026-10-20接续：Direct与Worker默认已接入[原生生产器](SDK_NATIVE_MEASUREMENT_API.md)，
紧凑结果直接交给规范输入；必要宿主镜像独立授权并提供传输/停止回执。模型
绑定实际网格且可按压力回收，数值快照不固定模型。受限容量联合发布、20秒
停顿根因、真实帧/输入时延、步行坡面和外部设备/API验收继续按原P0–P4推进。
