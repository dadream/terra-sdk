# Terra SDK 0.1.0 Developer Preview

This first developer preview freezes the initial reusable terrain runtime and
its package contracts. It is intended for integration evaluation, not a
production service SLA.

## Packages

- `terra-sdk-0.1.0-native.tar.gz`: C++14 static libraries, the versioned C ABI,
  public headers, CMake package metadata, native C/C++ examples, documentation,
  and license notices.
- `terra-sdk-0.1.0-miniprogram.tar.gz`: the same C ABI compiled to WebAssembly,
  the `TerraViewer` Web/Mini Program facade, WebGL renderer, runtime adapters,
  TypeScript declarations, documentation, and license notices.
- `SHA256SUMS`, `release_manifest.json`, and `terra-sdk-0.1.0.spdx.json` record
  the release identity and archive checksums.

## Supported Surface

The preview supports planar and globe terrain, CBDAM record decoding and LOD,
deterministic camera controls, progressive imagery, bounded caches, structured
diagnostics, basic POIs, one route, and surface sampling. Linux native,
WebAssembly/WebGL, and the checked-in WeChat Mini Program adapter are covered by
the automated release gate.

## Important Boundaries

Viewer, nav3d, builders, hosted terrain/imagery services, Docker images, and
datasets are reference infrastructure and are not included in the archives.
The Mini Program device acceptance status is recorded in
`release_manifest.json`; production approval remains pending until the owner
signs off the documented Android and iOS evidence.
