Licensing

A multi-license codebase, documented per release

Terra SDK is not presented as a single-license or all-MIT distribution. Review the exact notices shipped in the archive before redistribution or commercial use.

Authoritative files

The repository and both SDK packages include LICENSE, NOTICE, spacelib/COPYING, and ratman/LICENSE. Those files, not this summary, define the applicable terms.

Release evidence

Each tagged release publishes deterministic archive checksums, release_manifest.json, and an SPDX 2.3 JSON inventory. The SPDX inventory records package identity and checksums; it intentionally uses NOASSERTION where a component-wide conclusion has not been established.

Hosted data and imagery

Terrain datasets and hosted imagery are evaluation infrastructure and are not part of the SDK archives. NASA Blue Marble and Tianditu have their own source and attribution requirements. Applications using Tianditu must display © 天地图 and follow the provider's current terms.

No service warranty

The public endpoints and Developer Preview packages are supplied for engineering evaluation without a production service-level commitment. Security, availability, data rights, and provider credentials remain application-owner responsibilities.
