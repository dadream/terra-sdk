公开评估基础设施

地形与影像服务

使用这些端点即可评估 Terra SDK，无需自行部署数据仓库。服务为尽力而为的测试基础设施，不提供生产可用性或数据保留 SLA。

平面地形

PS 1k

CBDAM 地形仓库及配套分块影像。

/terra/v1/datasets/ps-1k/manifest

/terra/v1/imagery/ps-1k/{z}/{x}/{y}.jpg

打开平面演示 →

球面地形

全球大地坐标

由 SRTM 派生的 CBDAM 记录，用于全球地形评估。

/terra/v1/datasets/globe/manifest

/terra/v1/datasets/globe/patches/{level}/{x}/{y}

打开球面演示 →

开放影像

NASA Blue Marble

公开球面配置默认使用的全球影像。

/terra/v1/imagery/blue-marble/{z}/{x}/{y}.jpg

版权标识：影像：NASA Blue Marble。

代理影像

Tianditu img-c

服务端保护访问凭据并缓存成功瓦片。应用必须保留可见的天地图版权标识，并遵守服务商条款。

/terra/v1/imagery/tianditu/img-c/{z}/{x}/{y}.jpg

版权标识：© 天地图。

使用天地图打开球面演示 →

备案期间的访问地址

备案完成前使用临时地址 http://49.233.185.96；域名解除拦截后使用 https://terra.tapirs.top。浏览器演示采用同源 URL，不会为临时 HTTP 访问降低 SDK 安全策略。

合理使用

请勿批量下载公开测试数据、将端点作为 CDN 使用或嵌入服务商凭据。生产环境应部署独立的地形服务和影像策略。自动化测试结束时必须停止轮询并关闭浏览器上下文。
