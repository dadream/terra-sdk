Origins during filing

The temporary pre-filing origin is http://49.233.185.96. After the domain filing block is removed, use https://terra.tapirs.top. The browser demos use same-origin URLs, so no SDK security policy is weakened for temporary HTTP access.

Responsible use

Do not bulk-download the public test datasets, use the endpoints as a CDN, or embed provider credentials. For production, deploy your own terrain service and imagery policy. Automated tests must stop all polling and close their browser contexts when validation completes.
