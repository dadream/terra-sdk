快速开始

集成经过验证的软件包边界

请从带 Tag 的归档开始，而不是复制源代码模块。Release 包含完整示例、CMake 元数据、运行时声明、校验和及许可声明。

Native C++14

解压原生归档，并让 CMake 指向其安装包目录。

tar -xzf terra-sdk-0.1.0-native.tar.gz
cmake -S my-app -B build \
  -DTerraSdk_DIR="$PWD/terra-sdk-0.1.0-native/lib64/cmake/TerraSdk"
cmake --build build
find_package(TerraSdk 0.1 CONFIG REQUIRED)
target_link_libraries(my_app PRIVATE Terra::core Terra::frame)
target_compile_features(my_app PRIVATE cxx_std_14)

稳定的 C 边界使用 Terra::c_api，仓库解码使用 Terra::codec。可运行的 C 与 C++ 消费端示例安装在 share/doc/TerraSdk/examples。

Web 与小程序

跨端归档包含 wasm/terra_sdk.wasm、utils/ 中的 CommonJS 运行时模块和 terra_viewer.d.ts。宿主创建 Wasm 模块，提供 Canvas 与请求适配器，然后构造 TerraViewer。

const viewer = await TerraViewer.create({
  mode: 'globe',
  canvas,
  serviceOrigin: 'https://your-terrain.example',
  manifestPath: '/terra/v1/datasets/globe/manifest',
  terraModule,
  request,
  imagery,
  viewport: { width, height, devicePixelRatio }
})

通过 viewer.interaction 绑定指针或触控事件；通过 viewer.camera 提供确定性控制；并将 viewer.resize、pause、resume 与 destroy 接入宿主生命周期。
