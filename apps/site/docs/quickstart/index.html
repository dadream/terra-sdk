Quickstart

Integrate the verified package boundary

Start from a tagged archive rather than copying source modules. The release contains complete examples, CMake metadata, runtime declarations, checksums, and notices.

Native C++14

Extract the native archive and point CMake at its installed package directory.

tar -xzf terra-sdk-0.1.0-native.tar.gz
cmake -S my-app -B build \
  -DTerraSdk_DIR="$PWD/terra-sdk-0.1.0-native/lib64/cmake/TerraSdk"
cmake --build build
find_package(TerraSdk 0.1 CONFIG REQUIRED)
target_link_libraries(my_app PRIVATE Terra::core Terra::frame)
target_compile_features(my_app PRIVATE cxx_std_14)

Use Terra::c_api for the stable C boundary or Terra::codec for repository decoding. Working C and C++ consumers are installed under share/doc/TerraSdk/examples.

Web and Mini Program

The portable archive contains wasm/terra_sdk.wasm, CommonJS runtime modules in utils/, and terra_viewer.d.ts. The host creates the Wasm module, supplies a canvas and request adapter, then constructs TerraViewer.

const viewer = await TerraViewer.create({
  mode: 'globe',
  canvas,
  serviceOrigin: 'https://your-terrain.example',
  manifestPath: '/terra/v1/datasets/globe/manifest',
  terraModule,
  request,
  imagery,
  viewport: { width, height, devicePixelRatio }
})

Bind pointer or touch events through viewer.interaction, use viewer.camera for deterministic controls, and call viewer.resize, pause, resume, and destroy with the host lifecycle.

Verify the download

sha256sum -c SHA256SUMS

Read release_manifest.json for ABI and package identity and the SPDX JSON inventory for release checksums and licensing context.
