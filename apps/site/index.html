One runtime, three surfaces

Terrain detail where the viewport needs it

CBDAM refinement, hierarchical imagery, and deterministic camera state remain platform-neutral. Applications supply only rendering, transport, and interaction adapters.

Planar and globe

Use the same public viewer facade for local terrain repositories and global geodetic datasets.

Progressive imagery

03

Portable core

C++14 libraries and a versioned C ABI avoid Qt, OpenGL, network, and operating-system dependencies.

04

Observable behavior

Structured camera, terrain, texture, cache, and frame state make integration failures diagnosable.
